# Burn
Burn ICE


an interactive, text-based terminal simulation game set in the grimdark universe of Warhammer 40,000. Players step into the cybernetic augmentations of a Tech-Priest of the Adeptus Mechanicus, tasked with isolating, analyzing, and purging a catastrophic scrap-code infection within a localized cogitator network.
The Omnissiah watches. Failure to excise the corruption will result in immediate servitor conversion—or worse.
